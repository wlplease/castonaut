Know what can cost money.

The 4-vCPU VM, 1.75-TiB data disk, and 30-GB boot disk are about $0.24/hour or $40 for seven days, before network and IP charges. The current Google Cloud account shows $300 of trial credit for 90 days, which covers about 53 days at this rate; the trial ends sooner if the credit runs out. The project has a $25 monthly budget with 50%, 80%, and 100% email alerts that count gross usage before credits. Alerts do not cap spending. Keep the account in trial status, monitor usage, and run npm run destroy -- us-central1-a after your test to delete the VM, disk, and firewall rule.

02PROTOCOL BASICSTHE PIECES BEHIND THE WINDOW

Small pieces.
Clear responsibilities.

This section is for curious builders who want to understand the path from account to message.

A / IDENTITY
FID

FID

A Farcaster ID is the protocol’s numeric identity. It points to account state; it is not a password or a private key.

B / CUSTODY
⌑

Custody address

The Ethereum address registered to the FID. It authorizes signer changes and controls the account’s recovery path.

C / APP ACCESS
KEY+

Scoped app key

A separate Ed25519 key signs app messages. Gasless KEY_ADD is authorized by an EIP-712 custody signature and restricts message types.

D / STORAGE
▤

Storage rent

An existing FID needs protocol storage units to publish messages. This client does not register new accounts or buy storage.

E / MESSAGE
✉

Snapchain message

A signed, encoded message such as a cast, follow, or reaction. Castonaut signs it in your browser and sends it through the app service.

F / NODE ROLE
R ≠ V

Read node / validator

Your read node follows decided blocks and serves APIs. It can accept a signed message and relay it to validators; validators propose and vote on blocks.

DEVELOPER TEST MODELOCALHOST ONLY

Use a disposable account for phrase import.

The contest asks you to demonstrate an existing stored account. Castonaut exposes a developer-only phrase import only on localhost, where derivation and EIP-712 signing happen in the browser. The phrase is cleared from the field and never sent to a server. Do not paste a valuable account’s seed phrase into a new client; run the local source you have reviewed and use a throwaway test account.

  • Use only a test account whose custody key you control.
  • Check that the FID is already registered and has storage.
  • Grant only cast, follow, and reaction scopes.
  • Revoke the app key from custody when the test is finished.
04CLIENT SOURCEINCLUDE OR HIDE BY APP

Your feed.
Your source lens.

Castonaut can filter by the app FID associated with a cast’s signer when that attribution is available from the node.

CAST / FID 12APP FID 123
CAST / FID 28SOURCE UNKNOWN
CAST / FID 81APP FID 123

Attribution has limits.

For gasless app keys, Snapchain signer records can associate a signer with a requester FID when the requesting app uses its own FID. Older signers, missing metadata, self-requested keys, or unrecognized signers may not identify a client. Castonaut labels those casts “source unknown” and never guesses.

The source field is an aid for personal feed control, not proof of authorship or a complete audit trail.

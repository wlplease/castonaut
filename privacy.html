1. At a glance

  • Castonaut has no account database. The client interface requires a prepaid Time Pass when its Base contract is configured; checkout is not active until the operator deploys and sets that contract address. There is no automatic renewal. This UI gate does not restrict public protocol data or direct access to a public Snapchain endpoint.
  • Farcaster posts, profiles, follows, reactions, signer records, and Base pass purchases are public network data.
  • Your app signing key, payment-wallet address, Time Capsule snapshots, and personal curation settings are stored in this browser. They are not synced by Castonaut to an account server.
  • Recovery phrase entry is optional. If you enter a phrase, this page’s code can read it while you use it. The app derives the first five standard account slots locally, checks their public addresses against Farcaster’s ID Registry, clears the input before lookup, and does not intentionally send or save the phrase or custody private key. A linked wallet avoids putting the phrase into the page.
  • Production Vercel Web Analytics sends no page-view events unless you opt in under About → Local by default.
  • Remote profile, cast, GIF, and image previews are off by default. If enabled, your browser requests media from the hosts named in Farcaster data; those hosts can see your IP address.

2. Data and where it goes

Farcaster account and public network data

When you open a feed, Castonaut sends the requested numeric FIDs and other query fields to the Snapchain endpoint configured by the app operator. The feed service returns public casts, profile fields, follow links, signer records, and related network data. The app may query the Optimism ID Registry to match a custody address to an existing FID. Reads and writes are handled by Snapchain; the protocol network distributes messages that are accepted.

Social actions

If you post, reply, follow, like, or recast, your browser signs a protocol message with the limited app key and sends the encoded, signed message to the configured Snapchain service for relay. That message contains the information needed for the selected action and may become public network data. A successful relay is not a guarantee that every client will display it or that it cannot later be removed under protocol rules.

Recovery phrase and custody key

The optional phrase flow processes the phrase in page memory and derives the first five standard account slots locally. The app checks their public custody addresses against the public Optimism ID Registry and uses the first matching Farcaster account. The phrase field is cleared before those network lookups. The app does not intentionally send the phrase or custody private key to Castonaut’s server or the registry, and it does not store them in localStorage or IndexedDB. This describes the source code and header configuration reviewed in this repository; it cannot verify what a live deployment actually serves or what browser extensions, malware, developer tools, or a compromised device may do. The page can read a phrase while it is entered. The app shell references only its same-origin application script and styles; it does not include third-party-hosted JavaScript. Vercel's same-origin analytics script is injected only after opt-in, with automatic route tracking disabled. Its production Content Security Policy blocks inline scripts, inline event handlers, frames, and object embeds. The app still makes first-party service requests and, when features are used, direct requests to Optimism, Base, GIPHY, and user-selected HTTPS media hosts. Only enter a phrase on a deployment you control after verifying the live source and headers. A linked wallet avoids putting the phrase into the page.

Wallet, pass, and blockchain providers

If you connect a wallet, its browser extension or wallet provider receives the connection and signing requests. The selected wallet or RPC provider may process your IP address, wallet address, chain requests, and transaction/signature metadata under its own terms. The $3.70 Time Pass is a one-time 30-day purchase in native USDC on Base, with no automatic renewal. Its contract stores the payment wallet address and expiry publicly on Base; it is not linked to your Farcaster FID in Castonaut’s database. A public Base RPC receives pass-status requests containing the wallet and contract addresses. The wallet signs an exact USDC allowance and the purchase; Base network fees are paid separately in ETH. The app-key authorization for Farcaster remains a separate gasless typed signature, not a token approval.

Hosting and service requests

In hosted mode, your browser requests Castonaut’s web host and same-origin Snapchain API. The function uses the connecting IP address transiently in memory to apply a per-instance rate limit. Castonaut does not intentionally store that address in its own user database. The hosting provider may process IP addresses, device/request metadata, diagnostics, and platform logs to deliver, secure, and operate the service; its own retention and use are governed by its privacy notice and your deployment configuration. The configured Snapchain node receives the application’s requests from the host’s network egress and can process the request fields and signed messages sent to it.

Optional Gemini catch-up

Only after you click Summarize posts, the browser sends up to 20 visible cast texts (each limited to 320 characters) to the Castonaut same-origin API. The server validates and caps the request, then sends those texts to Google Gemini with a request to summarize them. It does not send FIDs, profile notes, feed metadata, or the signer key as part of this feature. Gemini returns generated text through the server to the current page; Castonaut does not intentionally retain prompts or results. The Gemini provider may process prompt data under its applicable terms and retention practices. Treat feed content as public and do not summarize sensitive material. The endpoint applies a best-effort limit of five requests per minute per function instance and returns cache-disabled responses.

Optional GIPHY search

Only after you submit a GIF search, the browser sends your exact search phrase directly to GIPHY’s Search API, as required by GIPHY. GIPHY receives the browser’s IP address and request metadata with the query. Search thumbnails also load from GIPHY after you request results. The GIPHY API key is a public web-app key embedded in Castonaut’s built JavaScript; it is not a secret, and the operator should use a dedicated key and monitor its usage. Castonaut displays up to nine results and does not intentionally retain search phrases or results. GIPHY may process the query and requests under its own terms. Without a configured key, direct media URL attachment remains available.

Links and embedded media

Link cards are built from the URL already present in a cast; Castonaut does not fetch a remote preview service. GIFs and images are attached as URLs, not uploaded to Castonaut. If you open an external link, the destination site receives your request and may see your IP address and browser information. If you enable remote images, your browser directly requests the relevant image host. Media is loaded lazily and without a referrer, but the host still sees the request and IP address.

3. Information kept in this browser

Castonaut stores these items locally so the station can remember your setup on this device:

  • IndexedDB: the separate Ed25519 app key as non-extractable Web Crypto key material, its public key, FID, and custody address. Browser storage protections are not the same as hardware-backed custody. Anyone who controls this browser session or device may be able to use the app or inspect stored metadata.
  • Local storage: theme and voice preference; payment-wallet address; up to 14 daily Time Capsule snapshots, each containing up to 30 visible post texts and public cast identifiers; pinned people, saved Desk signal text and topic shortcuts; saved casts and profile notes; Friends and Crew lists; muted authors/topics; feed filters and compact mode; feed scroll positions; per-account post drafts and queued thread text/signed pending cast; local profile pins and cover choices; and your analytics choice.
  • Temporary page memory: the phrase only during local derivation, then a derived account signer while you review and authorize a limited app key; feed responses, pass expiry, and pending UI state. Closing the dialog or finishing the authorization attempt clears that signer reference. The phrase variable is overwritten after derivation. JavaScript cannot guarantee secure memory zeroization.

Settings and saved items do not sync automatically. You can export a portable backup of Desk pins, saved posts, Time Capsules, profile notes, and selected appearance/feed preferences. The JSON file is created in your browser and is not uploaded to Castonaut. It can contain post text and private notes, so store it carefully. It never includes the app signing key, recovery phrase, payment-wallet address, or composer drafts. Restoring a backup replaces matching local values after confirmation. Clearing this browser’s data removes the saved payment-wallet address but does not affect a pass already recorded on Base. Anyone with access to your unlocked browser profile may see local notes and saved casts. Use “Forget this browser” to delete the local app key; this does not revoke the signer from Farcaster. Revoke it separately from Farcaster account signer controls.

4. Your choices

  • Analytics: opt in or out under the app’s About page. With no opt-in, the app’s Vercel Analytics hook drops the event before sending it. Your choice is kept locally on this device. Opting out stops future events; it does not delete historical aggregate data already collected by Vercel. Clear site data to reset the choice.
  • Remote images: leave “Load remote images” off in Feed → View options to prevent direct image requests from this browser.
  • Recovery phrase: use a linked wallet if you do not want the page to handle a phrase. Never enter a phrase into an untrusted site.
  • Local data: clear this site’s browser storage or remove individual local items in the app. Revoke a protocol signer separately through Farcaster.
  • Public protocol data: Castonaut cannot erase or control network data. Use the protocol’s account and message-management tools where available.

5. Optional Vercel Web Analytics

In production, the app uses @vercel/analytics only when you have opted in. It sends page views only; Castonaut does not send custom events, feed text, FIDs, wallet addresses, recovery phrases, profile notes, or saved casts to analytics. Before an event is sent, the app removes the URL query string and fragment. Vercel describes Web Analytics as using a short-lived hashed visitor identifier rather than third-party cookies, with aggregated reporting; page-view data can include timestamp, page path, referrer, coarse location, operating system/browser, and device type. See Vercel’s Web Analytics privacy documentation. Vercel separately processes technical data to host and secure the site under its Privacy Notice.

6. Providers and other services

Castonaut relies on the operator’s web host and Snapchain endpoint, the Optimism public network and registry, the Base network and public RPC, the native USDC contract, and—if you choose them—your wallet provider, external image hosts, and external link destinations. These services are independent and apply their own privacy terms. Castonaut does not control their security, uptime, or retention. The operator should list the actual deployment providers and their privacy contacts here before public launch.

Castonaut does not use advertising pixels or a Castonaut account cookie. The optional Gemini catch-up processes post text only when requested by the user.

7. Retention and security

Local settings remain until you remove them or clear browser data. Castonaut’s in-memory rate-limit counters are used for request control and are not written by this app to a database. Farcaster protocol messages and public profiles follow the network’s storage and deletion behavior. Analytics retention is controlled by Vercel and the deployment plan. Hosting and node logs may have separate retention settings. No browser or internet service can promise perfect security; use a current device and browser, protect your device, and revoke a signer you no longer trust.

8. Privacy requests, children, and changes

Privacy rights depend on where you live and what law applies. Because Castonaut does not currently maintain an account database, most app preferences can be removed directly from your browser. Requests about hosting records, protocol data, or legal rights need a monitored operator contact. Add the real contact above before launch; do not send recovery phrases, private keys, or seed words in a privacy request.

Castonaut is not designed for children under 13. Do not use it if you are under 13. If the operator learns that a child under 13 has provided personal information directly to a Castonaut-controlled system, the operator should delete it and take appropriate steps.

This notice may change as the client or providers change. The current version and effective date will appear here. Material changes should be announced in the app or its official distribution channel.
